# Customer Revenue Analytics SQL
📊 About This Project

In this project, I explored a real Brazilian e-commerce dataset (Olist) to better understand revenue performance and customer behavior over time.

Using MySQL as the main tool, I analyzed monthly revenue trends, identified top customers, calculated growth rates, and examined retention patterns. The goal was to simulate real business questions and answer them through structured SQL analysis.

This project helped me strengthen my understanding of aggregations, window functions, ranking, moving averages, and customer-level metrics, while focusing on generating insights that could support business decisions.
